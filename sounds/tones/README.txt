مجلد نغمات التطبيق
==================
كل نغمة هنا يقدر المستخدم يختارها في: الإعدادات ← إشعارات الرسائل
(للأصدقاء، المجموعات، البرودكاست، والوكزة كل واحد لحاله).

لإضافة نغمة جديدة:
1) حط ملف الصوت هنا (mp3 أو wav أو m4a) — أقل من 30 ثانية، ويفضّل ثانية أو ثانيتين.
2) أضف سطر في tones.json بنفس الشكل:
   { "id": "اسم-انجليزي-بدون-مسافات", "name": "الاسم اللي يظهر للمستخدم", "file": "اسم-الملف.mp3" }
   - الـ id: حروف إنجليزية صغيرة وأرقام و - فقط.
3) ارفع التعديل وابنِ التطبيق. البناء يحوّل كل نغمة تلقائيًا لصيغة إشعارات الآيفون.
